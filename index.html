Elder Mate

长辈生活助手
Edge-based voice & life assistant with ESP32, Home Assistant and LLM
Working Prototype · 可运行原型

I built a software‑hardware integrated voice assistant to explore how natural conversation and LLM capabilities can help parents handle daily tasks more easily. The system uses an ESP32‑S3‑BOX‑3 as the voice input/output node, connects to XiaoZhi AI (cloud LLM) for intent recognition, and uses the MCP protocol to enable automatic software function calls. The full loop — voice wake‑up, intent recognition, and function calling — is already working. The next step is to implement proactive voice alerts for scheduled reminders. 我做了一个软硬件集成的语音交互助手，探索如何用自然对话和大模型能力，帮助父母更方便地完成日常事务。系统以 ESP32-S3-BOX-3 作为语音采集与播放节点，接入小智 AI（云端 LLM）完成意图识别，通过 MCP 协议实现软件功能的自动调用。目前已完成语音唤醒、意图识别与功能调用的完整链路，下一步会做主动播报功能，用于定时提醒等场景。

Multi-Cat ID

多猫识别系统
Edge-based feline face recognition with YOLOv8, trained and validated on Raspberry Pi
Perception Prototype · 感知层原型

I trained a multi‑cat recognition model to explore how edge AI can enable personalized feeding. Training data was collected from two sources — a Raspberry Pi camera module and an iPhone. I used the lightweight YOLOv8n vision classification model and ran real‑time tests on a Raspberry Pi. The next step is to build the hardware execution layer for precise feeding. 我训练了一个多猫识别模型，探索边缘 AI 如何实现个性化喂食。训练数据来自树莓派摄像头模组和 iPhone 两种采集源，采用了 YOLOv8n 视觉分类模型，并在树莓派上完成了实时测试。下一步会做精准投喂的硬件执行部分。
